# YouNet Portal Desktop

Public distribution for the **YouNet Portal** desktop app — a native (Electron) client for the Bitrix24 messenger. The application source code is maintained privately; this repository hosts the downloadable builds only.

## Download

Get the latest build from the [**Releases**](https://github.com/younetgroup/yng-intranet-desktop/releases/latest) page.

| Platform | File | Notes |
|---|---|---|
| **macOS** (Apple Silicon + Intel, universal) | `*.dmg` | Signed with a Developer ID and **notarized by Apple** — open the DMG, drag to Applications, double-click. |
| **Windows** (x64) | `*Setup*.exe` (installer) / `*.exe` (portable) | Not code-signed yet → SmartScreen may show "Unknown publisher" → **More info** → **Run anyway**. |
